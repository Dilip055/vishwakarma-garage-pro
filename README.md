# Vishwakarma Garage Pro

A full-stack bike garage management application designed to simplify bike servicing and workshop operations.

## 🚀 Tech Stack

### Frontend
- Angular
- TypeScript
- HTML and CSS

### Backend
- Node.js
- Express.js
- Supabase

## 📁 Project Structure

```text
vishwakarma-garage-pro/
├── garage-frontend/
├── garage-backend/
├── .gitignore
└── README.md
```

## ✨ Features

- Bike servicing and repair management
- Service booking interface
- Responsive user interface
- Backend API integration
- Database integration with Supabase

## ⚙️ Getting Started

Clone the repository:

```bash
git clone https://github.com/Dilip055/vishwakarma-garage-pro.git
cd vishwakarma-garage-pro
```

### Frontend Setup

```bash
cd garage-frontend
npm install
ng serve
```

### Backend Setup

Open another terminal:

```bash
cd garage-backend
npm install
```

Configure the required environment variables before starting the backend.

## 🔐 Environment Variables

Keep credentials and secrets in local `.env` files. Never commit API keys, passwords, or other sensitive information to GitHub.
